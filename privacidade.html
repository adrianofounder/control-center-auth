Política de Privacidade

Esta política descreve o tratamento de dados pelo Control Center Auth, uma integração de uso pessoal executada localmente em um computador Windows.

Dados consultados

Quando o titular autoriza uma Conta Google, o aplicativo pode consultar os serviços selecionados no consentimento, incluindo identidade, informações de perfil, projetos e faturamento Google Cloud, Google Drive, Calendar, YouTube e leitura de mensagens Gmail pertinentes às consultas autorizadas. Cada API possui controles próprios de acesso.

Finalidade e uso limitado

Os dados servem para oferecer inventário e consultas a contas, cobranças, benefícios, documentos e notificações relevantes solicitadas pelo titular. O uso de informações obtidas pelas APIs do Google respeitará a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

Armazenamento e proteção

As credenciais de renovação são protegidas no dispositivo pelo Windows DPAPI. Informações de inventário e registros de consulta podem ser guardados localmente. Senhas, códigos de verificação, números completos de cartão e tokens não são gravados em relatórios comuns. O aplicativo não vende dados pessoais nem os utiliza para publicidade.

E-mails

O acesso ao Gmail, quando concedido, é somente de leitura para consultas solicitadas, como recibos, vencimentos e avisos de pagamento. Este consentimento não permite enviar, apagar, arquivar, marcar como lida ou modificar mensagens. Regras de organização futuras exigem autorização específica separada.

Compartilhamento e retenção

As consultas envolvem comunicação com as APIs oficiais do Google. O aplicativo não realiza compartilhamento automático de conteúdos com terceiros. Os registros locais são mantidos para consulta do titular, que pode solicitar sua remoção e revogar as autorizações no painel de segurança Google.

Controle pelo titular

O titular pode consultar os dados registrados no aplicativo, revogar o acesso Google a qualquer momento em Conexões da Conta Google e excluir os registros locais conforme os controles disponíveis.
